01 / About

저는 이런 사람입니다

브라우저가 이해하는 유일한 언어인 HTML, CSS, JavaScript 부터 차근차근 익히고 있습니다. 화면을 그리는 것에서 멈추지 않고 사용자 이벤트 → 상태 변경 → 화면 업데이트로 이어지는 흐름을 코드로 설명할 수 있는 개발자가 되는 것이 목표입니다.

이 페이지도 프레임워크 없이 직접 만들었습니다. 다크 모드 · 햄버거 메뉴 · 스크롤 애니메이션은 모두 DOM API 로 구현했고, Projects 섹션은 GitHub REST API 를 호출해 로딩 · 성공 · 실패 · 빈 상태를 직접 처리합니다.

  • 관심 분야 프론트엔드 · AI 도구 활용
  • 지금 배우는 것 DOM · 비동기 · 곧 React
  • 연락 your-email@example.com
